start / what to do

  1. Keep the node running. tapseal-node service install keeps it on after you close the terminal.
  2. Wait for sync. INDEXED BLOCK above shows synced ✓ when ready.
  3. Find a proof. Go to mint → pick a token → paste your bc1p… address → start.
  4. Claim it. Copy the proof → tapseal.xyz/mining ↗ → connect the same wallet → sign.

This console never asks for a seed phrase, private key or deposit.

mint / find a proof

Your computer searches for one mint proof, then stops. Nothing is paid from here. The main token uses 450 sats per 1,000 tokens for approved proof claims; approval and a valid proof are both required.

  1. Pick a token — only open proof mints show up.
  2. Paste your bc1p… address — from the wallet you will claim with. Never a seed phrase.
  3. Start — wait for ✓ Proof ready.
  4. Copy proof → claim page — connect the same wallet, check fees, sign.

Good to know

This is not Bitcoin mining and it does not earn rewards. A proof can expire, or miss if supply runs out first. Keep the node service on to keep searching with this page closed; a sleeping computer stops. The node can’t sign, send or change mint rules.
