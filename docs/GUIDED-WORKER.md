# Guided worker documentation

The current user guide is [Mint worker](MINT-WORKER.md). For installation and retained network profiles, use [Quick start](QUICKSTART.md); for the current build/version, use [Development and release](RELEASE.md).

The earlier 1.3.1 guided release introduced the token picker and restricted local console. Its old deployment/download commands have been replaced here to avoid installing an obsolete runtime. Current lot-mode pricing and activation are specified in [LOT-V1](LOT-V1.md). Existing non-lot token rules remain unchanged.
